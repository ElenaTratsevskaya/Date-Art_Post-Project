# Date-Art_Post-Project
Date Art on these postal items


Почтовый проект возник из мероприятия сообщества “Цветы и Цифры”. 
🆒 Вот тут есть затейное, отличное от прочих.

Идея возникла после оффлайн встречи, к которой были изготовлены футболки с принтом и открытки. Кто-то не смог приехать.
📩 Тем, кто не смог попасть на встречу, открытки отправили. 
Так возник почтовый проект, который и сейчас продолжается, 
✉️ сама в нём участвовала, получила открытку.

Есть датасет с данными почтовых отправлений, по которому я создала Дата-Арт. 

# Идея
Сразу решила сделать по принципу “Розы ветров”: 
1️⃣ линии направлений сторон света немного изогнула, 
2️⃣ фон как стрелка компаса, которая цветом делится пополам, синяя - север, красная – юг, 
3️⃣ далее: расстояние с традиционным масштабом и время в пути плашками.
▶️ Всё есть в легенде.
