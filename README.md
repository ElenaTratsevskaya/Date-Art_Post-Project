# История возникновения проекта 
</br>
Идея возникла после оффлайн встречи, к которой были изготовлены футболки с принтом и открытки. Кто-то не смог приехать.</br>
📩 Тем, кто не смог попасть на встречу, открытки отправили. </br>
Так возник почтовый проект, который и сейчас продолжается, </br>
✉️ сама в нём участвовала, получила открытку.</br></br>

Есть датасет с данными почтовых отправлений, по которому я создала Дата-Арт.</br></br> 

# Идея Дата Арта
Сразу решила сделать по принципу “Розы ветров”: </br>
1️⃣ линии направлений сторон света немного изогнула, </br>
2️⃣ фон как стрелка компаса, которая цветом делится пополам, синяя - север, красная – юг, </br>
3️⃣ далее: расстояние с традиционным масштабом и время в пути плашками.</br>
▶️ Всё есть в легенде.</br></br>
